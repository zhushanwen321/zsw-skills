# W25 Contract Skill

## 概述

帮助用户生成、管理和追踪每周工作周报，保持结构化记录。

## 功能

1. **生成周报模板** — 基于工作目录和 Git 历史自动生成
2. **汇总本周工作** — 从 commits、PR、issues 提取关键事项
3. **目标追踪** — 对比上周目标与本周完成情况
4. **周报历史** — 查阅过往周报记录

## 输出格式

```markdown
# 周报 — YYYY-MM-DD ~ YYYY-MM-DD

## 本周完成
- [x] 事项1
- [x] 事项2

## 进行中
- [ ] 事项3

## 下周计划
- [ ] 事项4

## 遇到的问题
- 问题描述及解决方案

## 备注
- 其他补充
```

## 工作流程

1. 询问用户需要生成还是查看周报
2. 如需生成，检查 Git 日志和项目状态
3. 生成结构化周报供用户审阅和补充
