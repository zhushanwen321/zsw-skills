# 事实核查文档

分类三值：**事实**（已核实，证据=文件:行号 或探针输出文件）、**推断**（合理推导未核实）、**虚构**（无依据臆断——须标「作废」并删除依赖它的方案分支）。
纪律：最终设计只准建立在事实上；推断须升级为事实或进「未核实风险」；虚构作废。
