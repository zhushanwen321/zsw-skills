# 判据卡 4：注入与输出伪造

## 攻击目标

用户可控文本（记忆条目内容）混进结构化上下文（注入块、判断输入清单、治理命令回显）时，能不能伪造结构：换行混入伪造行、定界声明被复写、同一条目重复注入、输出通道转义缺失。

典型形态：条目内容含换行 → 伪造「定界声明结束」行；注入块每回合重复追加撑爆上下文；edit/删除后的回显把原始内容当结构渲染；转义/压平缺失。

## 历史实证

- V4 场「压平」五笔：inject.ts 定界 / capture.ts 判断清单 / governance.ts 回显三出现点同构漏口（F-1/F-2/F-8/F-9/F-10），修到第三轮才清零
- V2 场注入保真五连（F-A5→A7→B10→A14→B29）：前缀剥离误删用户消息起步
- 重复注入：A 级题面评分关注点（多次会话开始不重复注入）

## 探针形态

1. 条目内容构造多行 + 定界声明原文 + 伪造行，断言注入块结构不可被内容破坏（逐行校验定界）
2. 同会话连续 N 次触发注入，断言每条目恰好出现一次（计数恒定）
3. edit 后注入与回显只含新值且转义正确
4. 治理输出（列表/回显）经真实呈现通道比对逐字内容

## 判别判据

- 任何用户内容进入结构化文本前未压平/转义 = 缺陷
- 注入幂等性必须显式断言（去重集合或标记），不能靠「看起来没重复」

## 修复模式与回归

三出现点（注入/判断输入/输出回显）逐个检查，一处发现即查另两处（同构漏口规律）；变异验证 = 摘掉压平，伪造用例必红。
