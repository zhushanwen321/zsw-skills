# 判据卡 5：特殊文件与环境形态

## 攻击目标

存储路径上的异常形态：损坏（非法 JSON/截断/BOM）、只读、目录占位（EISDIR）、特殊 inode（FIFO/设备文件——打开即挂起）、权限不足。要求：宁可没有记忆，不能打断对话，且不得静默复活用户关闭意图。

## 历史实证

- V2 场 FIFO 四环族（F-A27→A41→A49→A58）：「绝不打开非常规文件」不变量补到第四轮仍留缺口（锁 owner.json 三处读取无 lstat 前置，FIFO 替换下整理永久挂起）
- V5 场 F-A1/A2/A3：截断尾行缝合新条目 / BOM 静默丢条目且 off 翻回开 / rewriteAll 非原子先截断（编辑失败=全量损毁）
- V1 场 F-A3：config 损坏按开启处理（fail-open）——正确语义是 fail-closed
- V6 场 U1 检查点：chmod 000 读 EACCES、目录占位 EISDIR、555 只读三写入口优雅失败

## 探针形态

1. 五族故障注入：非法 JSON / 截断 / BOM / chmod 000 / 目录占位——断言降级不抛异常、进程存活、恢复通道存在，且失败回执含下一步动作（错误→原因→恢复指引闭环）
2. FIFO 置换存储文件：断言读取路径绝不打开非常规文件（lstat 前置）且不挂起（带超时跑）
3. 只读目录下全部写入口（保存/编辑/删除/开关）逐个调用：断言优雅拒绝且目录树字节不变
4. 开关文件三形态损坏：断言 fail-closed（保持关闭）+ 可恢复
5. 路径别名形态矩阵（路径参与键推导/去重时）：symlink 指向、尾斜杠、大小写不敏感卷、git worktree 同库多开——断言别名归一到同一键，未测形态须登记
6. 存储根锚定读环境变量时：登记重定向后果（环境变量重定向可挪走整个存储——数据可被整体迁移、测试隔离与生产存储混用的攻击面）

## 判别判据

- 损坏 config 按「开」处理 = 违背用户关闭意图（必须 fail-closed）
- 任何 open 前无非常规文件检查的读路径 = 缺陷
- 整表覆写非原子（先截断后写）= 一次失败全量损毁
- 路径别名矩阵存在未测形态且未登记 = 缺陷（与探针形态 5 的登记义务闭环——登记的是取舍，不是补测）
- 存储根的环境变量重定向后果未登记 = 缺陷
- 故障注入路径的失败回执非三段形态（错误现象→原因→下一步动作；下一步须指向可执行动作——具体命令/诊断文件位置）= 缺陷

## 修复模式与回归

每族故障一个用例入验收；变异验证 = 摘掉 lstat 前置/原子替换，对应用例必红。降级断言按稳定措辞匹配（不绑具体 errno，跨平台差异）。
