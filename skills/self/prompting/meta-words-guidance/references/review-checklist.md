# 用语审查清单

对已写好的文字（文档、模板、提示词、注释、脚本输出文案）做用语审查的完整流程。只梳理问题、不改文字；改写另见 rewrite-guide.md。

## 审查流程

### 1. 圈定范围

明确审查对象类型：规则类（AGENTS.md / SKILL.md）、产出物模板（字段名、章节标题、示例文本）、说明文字（注释、脚本输出、错误信息）。三类都按"会被什么读者看到"定标准——模板按产出物读者，规则按执行者。

### 2. 残留词扫描

按全局 AGENTS.md「用语纪律」的已裁决替换 / 带条件保留 / 观察名单三张表逐词扫描（白名单与替换表「替换」列是放行词，不扫）。快速通道：`python3 ~/.agents/skills/meta-words-guidance/scripts/word-scan.py --all <目标路径>`——脚本解析 AGENTS.md 词表自动拉出全部命中（含替换建议），逐条复核即可。手工扫描或复核时 [MANDATORY] 必须追符号链接（`grep -R` / `find -L` / `os.walk(followlinks=True)`；脚本目录递归已内建追 symlink）——`grep -r` 与 `os.walk` 默认不追 symlink，真实文件在 symlink 指向的位置时整棵树会漏报。[HISTORICAL] 2026-09-24 实证：树遍历扫描报 0、直接读文件却有 41 处。

### 3. 逐句走查

每个可疑表述判下列八型之一，并判三种泄漏方式——泄漏方式决定严重度：

| 型 | 名称 | 一句话判据 |
|----|------|-----------|
| A | 砍字造词 | 把短语砍成两三个字当新词用 |
| B | 英文直译造词 | 英文短语逐字翻成中文黑话 |
| C | 流程指令词名词化 | 流程动作词被当名词、形容词用 |
| D | 行业黑话挪用 | 别的行业的词被搬来，字面推不出实义 |
| E | 四字自造成语 | 自造四字压缩语，靠解释才可读 |
| F | 电报式密度 | 一句嵌多层括号、裸编号，无法断句 |
| G | 同词多义 / 同义多词 | 一个词多义，或一个概念多个叫法 |
| H | 名实相反 / 歧义动词 / 切分歧义 | 名字与实义相反、动词有两种解读，或砍字后与邻字切分出另一种意思 |

三种泄漏方式（问题扩散到产出物的路径）：

| 泄漏方式 | 含义 | 危害 |
|--------|------|------|
| ① 模板直出 | 字段名、章节标题、状态词一字不改地进入每一份产出物 | 最高：批量污染每一份产出物 |
| ② 文风模仿 | 行文风格（电报密度、自造词习惯）被 AI 模仿 | 高：污染是弥漫式的 |
| ③ 术语搬运 | 术语被当常用词抄进文档/注释/commit | 中：逐点污染 |

### 4. 严重度判定

| 级 | 判据 |
|----|------|
| 高 | 会进产出物（泄漏方式①）、或会被理解成相反动作（歧义类）、或直接误导执行 |
| 中 | 需要作者背景知识才能理解，但不会反向执行 |
| 低 | 风格偏好，理解无障碍 |

歧义 > 难懂：同一个词两可时按"会不会被执行成相反动作"升级或降级。

### 5. 输出报告

逐条表格：`| # | 位置(文件:行号) | 原文引文（一行内） | 问题类型（写"名称(字母)"，如"电报式密度(F)"） | 为什么不懂/怎么污染产出物(注明泄漏方式) | 建议改法 | 严重度 |`

- [MANDATORY] 建议改法必须给具体替换词或完整改写示例，禁止只写"建议更清晰"——不可执行的建议等于没审。
- 报告末尾单列三节：「残留」（词表命中情况，含 0 命中的显式声明）、「同一概念的多个叫法」（同一概念在不同审查对象里叫法不一的清单）、「待裁决清单」（第 6 步的新增登记条目）。
- 每条判定给证据（原文引文 + 行号），不凭印象下结论。

### 6. 审查结束必须登记（自进化机制，每次审查必做）

审查发现就是词表和模式表的更新素材。收尾前对照本次逐条结果：

- 不在四张词表里的新词分类登记：疑似问题词 → AGENTS.md「用语纪律」观察名单表（每条带疑点 + 建议），疑似放行词（被误报的领域术语、按新词准入反复使用的自造简称）→ 白名单表「候选：」行（每条带准入理由，登记后即可用）；八模式没覆盖的新问题形态 → 登记进 patterns.md「候选模式」节（新立模式须 ≥2 个独立案例，不足的留在候选节等案例）
- 报告末尾加「待裁决清单」一节：把本次新增条目原样汇总，提示用户逐条裁决去向——确认生效（移入已裁决替换表 / 带条件保留表或留观察名单）、确认可用（白名单候选行去掉「候选：」前缀）、提升为 AGENTS.md 判据（具通用性的规则）、或丢弃
- 裁决执行后更新对应条目（移表 / 标注 / 删除）；词表与模式表只随用户裁决变更

## 判定原则

- 挑理解成本和污染风险，不挑口味。拿不准按"没有背景知识的读者第一遍能否准确理解"裁决。
- 高频口语词豁免：读者第一遍能懂的日常口语（"兜住""学样"式）不算问题——本 skill 挑的是理解成本与污染风险，不是消灭口语。
- 已裁决词（AGENTS.md 已裁决替换表）只要命中就记录，不再重新论证；白名单词与条件满足的带条件保留词直接放行，不记录。
- 禁令句里写的被禁词单独标注——它是"禁令失效"模式的证据，见 patterns.md。
- 同一问题在多处出现时逐处记录位置，但合并为一条（列全位置），不凑条数。
- **收敛判据**：高 0 + 中 0 + 自查通过 = 本轮收敛。自查 = 对照 SKILL.md 核心原则与关键约束，检查本 skill 自己的行文有无违反（修词时新造词、歧义句、多层括号等）。低级别的问题累积到下次使用时顺手修，不为它们无限重审。
