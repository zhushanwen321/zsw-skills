# 用语守卫

已写好的文字（文档、模板、提示词、注释等）的用语审查与改写，目标：没有背景知识的读者第一遍就能准确理解。

## 核心原则

1. **判据唯一**：没有背景知识的读者第一遍能否准确理解。拿不准按这条裁决，不按口味。
2. **歧义先于难懂**：会被理解成相反动作的表述（例如本意"正面修复"、却被读成"正式修复"的写法）最优先修；看不懂的其次；风格问题最后。
3. **替换用自然句，不用新造词**。拿新造词替换旧造词 = 换个地方重新污染。
4. **模板词就是产出物词汇**。模板字段名、章节标题、状态词会一字不改地出现在产出物里，按产出物读者的标准审。
5. **译词显式锚定**。中文译词（对应英文技术概念的词，判定与适用范围见全局 AGENTS.md「中文表达纪律」译词首现锚定条）首次出现括注英文原词——翻译链可见，读者才能核对原义，直译错误在锚定处当场暴露。中文原生词不需要锚定。

## 问题类型

| 型 | 名称 | 例子 |
|----|------|------|
| A | 砍字造词 | 认知外（改动）、被否 |
| B | 英文直译造词 | 在飞（in flight）、变化轴（axis of change） |
| C | 流程指令词名词化 | 被否说明、过堂记录 |
| D | 行业黑话挪用 | 保号、清账、盘面、树税 |
| E | 四字自造成语 | 宁合不裂、占位挣扎 |
| F | 电报式密度 | 一句嵌多层括号、裸编号（U8/A2/Gate B） |
| G | 同词多义 / 同义多词 | gate 一族八词混用、L0-L4 三套同名异义 |
| H | 名实相反 / 歧义动词 / 切分歧义 | 「示例空洞」实为缺示例；「一字不改进产出物」被切成「一字不改进」 |
| J | 句法层：名词语序直译 | 整句是英文名词短语的逐词直译：一段没打完的游戏（an unfinished game）、有了尺子才看得见方向、三步看清它到底是什么。句子通顺但中文母语者不会这么说 |
| K | 篇章层：版面形态替内容造效果 | 问题跨句出现，改词无效：标题用冒号+自评（硬证据：另一把尺子）、名词短语标题、全程加粗、破折号过密、同一比喻反复用 |

J/K 与 A–I 的分界：A–H 换词可解，I 拆句可解，**J 要还原谓语（把名词短语改回动词句）**，**K 要重排版面（改标题、调密度、换掉比喻）**。三类都要读原文，脚本只给候选。

## 关键约束

与全局 Agent 配置（AGENTS.md）的「用语纪律」一节配套，两层分工：AGENTS.md 是正式层——always-on 的表达判据 + 四张词表（已裁决替换 / 带条件保留 / 白名单 / 观察名单，唯一副本）；本 skill 是工具层 + 模式草稿层——管已写好的文字怎么审、怎么改，系统性模式数据落在这里。疑似问题词先登记进 AGENTS.md 观察名单（观察名单即其草稿态），疑似放行词先登记进 AGENTS.md 白名单「候选：」行（登记后即可用），新模式先进本 skill 候选模式，用户裁决后才移正。

- [MANDATORY] **替换词优先从全局 AGENTS.md「用语纪律」的已裁决替换表取**。表里没有的词，给出建议替换并报用户裁决，不直接拍板新词——因为新词会成为下一轮清理对象。
- [MANDATORY] **改词时把全部出现点一起改**：同一词的全部出现点（含引用、示例、模板、脚本输出、注释、commit message 范本）一起改。漏一处，残留词会被当合法用法继续传播。
- [MANDATORY] **禁令不列举被禁词**：写"决策条目用『不采用 X 的理由：…』"，不写"禁止使用『某某词』"。[HISTORICAL] 禁令句反复书写被禁词会诱发再产出——2026-09 两次清理实证：清掉的词从禁令句里被抄回产出物。
- [MANDATORY] **文字扫描必须追符号链接**：`grep -r` 和 `os.walk` 默认不追 symlink 目录，而全局 skill 的真实文件常在 symlink 指向的位置——整棵树的扫描漏报会得出"0 残留"的假阴性结论。用 `grep -R`、`find -L` 或 `os.walk(followlinks=True)`。[HISTORICAL] 2026-09-24 审查实证：树遍历扫描报 0 命中、直接读文件却有 41 处，曾导致审查报告被误判为"编造"。
- [MANDATORY] **审查结束必须登记（自进化机制）**：每次审查/改写收尾时，把 AGENTS.md 四张词表没覆盖的新词分类登记——疑似问题词进 AGENTS.md「用语纪律」观察名单表（每条带四要素：出处（文件:行）、原句（一行内引文）、含义（平实释义）、疑点；缺原句与出处的登记无效），疑似放行词（被误报的领域术语、按新词准入反复使用的自造简称）进白名单表「候选：」行（带准入理由），新模式候选登记进 `references/patterns.md`「候选模式」节（带案例；≥2 个独立案例才升正式模式）；执行结束把本次新增条目统一报用户裁决——确认生效（移入已裁决替换表 / 带条件保留表或留观察名单）、确认可用（白名单候选行去掉「候选：」前缀）、提升为 AGENTS.md 判据（具通用性的规则）、或丢弃。词表与模式表只随用户裁决变更（白名单候选行登记即可用），技能不自行升级词条或立新模式。不登记的后果：同类问题下次重新发现一遍，词表不再更新。
- [MANDATORY] **I 型（套式句式）扫描结果只是候选，不是违规报告**：`slop-scan.py` 用句式模板抓候选，但技术文档里「不是 A，而是 B」等句式**大量是真区分**（如「不是门面，是 JNI wire-format 的 ordinal 镜像」两侧都有具体名词）。**禁止按扫描命中直接改**——必须逐条读原文，按 I 型判据（两侧是否都是抽象描述）裁决。脚本输出已带回「两侧抽象词 N / 具体词 N」辅助标注，但它也只是提示，不是判据。
- [MANDATORY] **中英文 slop 规则分工**：英文 AI tells 归 `~/.agents/skills/unslop`（28 条，英文本体）；本 skill 管**中文句式**与中文语境判据。改中文本表时**不要搬 unslop 的英文规则条目**，只搬它在中文本里的表现形态。两者覆盖同一族问题、不重复。
- [MANDATORY] **J/K 型扫描同样只是候选，且假阳性率高于 I 型**：`structure-scan.py` 的标题检测按「无谓语 + 名词尾缀」判定，事实性概括标题（「一个反直觉的测量事实」）会被误抓；语序检测按定语性质分级，「一加5 的 60Hz 屏」这类事实性修饰已跳过，但边界仍需人工确认。比喻检测带技术义白名单（`采样窗口`/`过门槛`/`单帧成本` 不算比喻），白名单需随误报补充。
- [OPTIONAL] **密度阈值可调但不要当硬门禁**：`structure-scan.py` 默认加粗 >8 处/千中文字、破折号 >1.5 处/千字报候选。这是「视觉强调是否失效」的经验值，技术长文与口播稿差别很大——口播稿破折号多是节奏需要，技术文档加粗多是术语标记。超阈值只作提示，不构成必须修改的理由。
- [OPTIONAL] **新词准入**：领域标准术语（栈帧、提交、回滚）可直接用；自造简称只有在确实反复使用、且首次出现带一句解释时才准入。准入的自造简称登记进 AGENTS.md 白名单「候选：」行，报用户裁决后去掉前缀。
