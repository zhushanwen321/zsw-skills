accept — 通过接受

所有验收标准满足，任务完成，结束循环

next — 继续执行

verdict 为 fail 但可修复，或任务未全部完成，进入下一轮

reject — 拒绝终止

存在无法自动修复的阻塞问题，需要人工介入

pass — 审查通过

Review Agent 确认所有验收标准均已满足

fail — 审查未通过

存在未满足的验收标准，需要修复后重试

error — 流程异常

执行过程中出现不可恢复的错误
